# CODSOFT_TASKNO_2 — Movie Rating Prediction

This repository contains my submission for **Task 2** of the **CodSoft** internship program. The project is implemented as a Jupyter/Colab notebook (`movierating.ipynb`) and focuses on predicting movie ratings using data analysis and machine learning.

## 📌 Project Overview

The goal of this task is to build a model that can predict movie ratings based on available features in the dataset. The notebook walks through the complete data science workflow — from loading and cleaning the data to training and evaluating a predictive model.
